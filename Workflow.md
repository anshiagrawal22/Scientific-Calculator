## 🎯 Project Objective
The objective of this project is to design and develop a **GUI-based Scientific Calculator** using **HTML, CSS, and JavaScript**, ensuring an intuitive and user-friendly experience. 

### **Core Features**
- **Basic Arithmetic Operations** (Addition, Subtraction, Multiplication, and Division)
- **Advanced Scientific Functions** (Trigonometry, Logarithms, Exponentiation)
- **Mode-Switching** (Toggle between Basic and Scientific functionalities)

The project follows **Kanban and XP methodologies**, enabling:
- Iterative development
- Collaboration & teamwork
- Continuous improvement
- Effective user feedback integration
